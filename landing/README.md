# Mirror Atelier Landing

Create a landing page for the mobile app "mirror" (Nigerian Atelier Edition) based on the attached app screenshots.

Core requirements:
- Product concept: A makeup mobile app that allows users to take/upload a photo and simulate any makeup in real time using on-device face landmark detection and formulation engine, running fully offline.
- Brand & visual identity: Match the warm, mature atelier aesthetic from the attached screens — warm cream/linen parchment tones, deep charcoal/espresso contrasts, terracotta/burnt orange accents, elegant serif typography, clean pill buttons, refined micro-animations, and a tasteful initial loading splash screen with the minimalist "M" mark.
- Hero section: Warm, mature feel with moving pictures/carousel showcasing real-time simulated portrait looks, headline, and clear download/subscribe call-to-actions.
- Interactive look simulation preview: An engaging section demonstrating how the app works (uploading a portrait, selecting shade spectrums, eyeliner/lashes/blush/brows, and adjusting pigment saturation & intensity sliders in real time).
- Features & comparison: Detail the on-device formulation engine, certified shade library, and the distinction between casual personal use and Pro studio features (such as Client Mode Directory and studio vaults).
- Pricing page & checkout flow: Hybrid web checkout plus App Store & Google Play download badges. Include a pricing switcher for USD ($) and Nigerian Naira (₦) with two tiers:
  1. Casual / Personal: One-time payment (e.g. $19 / ₦15,000) for lifetime on-device simulation and personal looks.
  2. Pro Atelier Studio: Monthly subscription (e.g. $9.99/mo / ₦7,500/mo) for professional makeup artists and studios (unlocks Client Mode Directory, client profiles, unlimited shade formulations, and studio exports). Include a functional checkout modal/flow to complete purchase or subscription.
- Contact Us page: Clean support and studio inquiry form, along with FAQ.
- Flawless navigation, sleek responsive UI/UX, and comfortable, mature animations that aren't overwhelming.
